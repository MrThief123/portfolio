## 💻 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

### Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repository>.git
cd <your-repository>
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open the application at:

```text
http://localhost:3000
```

## 🎯 Design Philosophy

The portfolio focuses on three principles:

### **1. Show, don't just tell**

Projects are presented with visuals, videos, and interactive elements rather than relying solely on written descriptions.

### **2. Technical depth without unnecessary complexity**

Each project highlights the technologies and engineering decisions that matter while keeping the user experience accessible.

### **3. Projects as the centrepiece**

The portfolio is designed around the work itself — allowing visitors to quickly understand what was built, how it works, and the technologies behind it.
